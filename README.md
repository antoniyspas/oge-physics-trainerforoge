Веб-приложение для подготовки девятиклассников к **ОГЭ по физике**. В отличие от обычных сборников с фиксированными ответами, тренажёр **динамически генерирует новые числовые данные** для каждой задачи, автоматически пересчитывает ответ и формирует подробный пошаговый разбор с формулами.

---

## ✨ Основные возможности

### 🎯 1. Умный тренажёр задач (3 уровня сложности)
* **📘 Обычный уровень** — базовые расчётные задания первой части ОГЭ.
* **📙 Высокий уровень** — усложнённые задачи повышенного уровня.
* **📕 Комбинированные задачи (Тип 22)** — многошаговые задачи развёрнутой части на стыке нескольких тем.
* **Система 2 попыток:** при первой ошибке даётся шанс пересчитать задачу самостоятельно, а после правильного ответа или второй ошибки открывается полное оформление в формате **«Дано / Решение / Ответ»**.
* **Фильтрация по разделам:** можно тренировать отдельно *Механику*, *Тепловые явления* или *Электричество*, а также комбинировать их.

### 📚 2. Интерактивный справочник формул
Все необходимые для экзамена формулы, разбитые по 4 разделам (*Механика*, *Тепловые явления*, *Электричество*, *Оптика и квантовая физика*), отрисованные с помощью математической вёрстки $\LaTeX$.

### 🔬 3. Каталог физических приборов и устройств
Полная база приборов для заданий ОГЭ с указанием физических явлений и законов, лежащих в основе их работы (рычажные весы, манометры, психрометр, циклотрон, счётчик Гейгера и др.).

### 📊 4. Боковая шпаргалка констант
Быстрый доступ ко всем табличным величинам (удельные теплоёмкости, плотности, удельные сопротивления, теплота плавления и парообразования) прямо во время решения задачи.

## 🗂 Структура проекта

| Файл | Описание |
| :--- | :--- |
| `proekt.py` | Главный модуль приложения: пользовательский интерфейс (UI) на базе Streamlit, логика проверки ответов, хранение состояния сессии (`st.session_state`), справочник формул и база приборов. |
| `slovari.py` | Модуль базы данных: 9 словарей с шаблонами задач, `lambda`-генераторами случайных параметров, алгоритмами расчёта ответов и динамической сборкой решений. |
| `requirements.txt` | Список зависимостей для развёртывания проекта в облаке Streamlit Cloud. |
